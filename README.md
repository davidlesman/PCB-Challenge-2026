# UCL x KCL x Oxford x Imperial x Cambridge x Edinburgh: 2026 PCB Challenge | Sponsored by PCBWay and Jane Street

This is my entry for the PCB Challenge from the Fleming Society sponsored by PCBWay and Jane St, more information [here](https://github.com/Fleming-Society/PCB-Challenge-2026/).


The goal was to design a fully wired, single board PCB implementation of the given logic, optimized for the smallest possible board area.
